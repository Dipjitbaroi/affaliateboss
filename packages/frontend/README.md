@affiliateboss/frontend

This package contains the frontend (Vite).

Useful scripts (run from repo root):

```powershell
# Run frontend only
npm --workspace=@affiliateboss/frontend run dev

# Build
npm --workspace=@affiliateboss/frontend run build

# Preview
npm --workspace=@affiliateboss/frontend run preview
```

Notes
- Frontend is served on http://localhost:3000 in dev mode.
- Public assets are in `public/`.
